# claude-proto-kit

**ゲームのアイデアを、その日のうちに遊べる形にする**ための道具セットです。
Claude に日本語で頼むだけで、ブラウザで遊べるゲームの試作品（2D / 3D）を作り、URL で人に遊んでもらえます。
企画を説明するスライドや、紹介動画（PV）も同じように作れます。プログラミングの知識がなくても始められます。

## はじめかた

### 1. インストールする（最初の 1 回だけ）

パソコンに合わせて、どちらか 1 行をコピーして貼り付け、Enter を押します。必要なソフトはすべて自動で入ります。
あわせて、Claude への基本方針（あなたをプロのゲーム開発チームの一員として扱い、作り方・売り方・チームでの動き方まで
プロの水準で一緒に考える。大事な操作の前は確認する、など）をまとめたファイル `~/.claude/CLAUDE.md` も置きます。
すでにある場合は、置き換えるかどうかを聞きます。あとで自由に書き換えられます。

**Windows**：スタートメニューで「PowerShell」を開いて貼り付ける

```powershell
irm https://raw.githubusercontent.com/Waseda-Game-Co-creation-Studio/claude-proto-kit/main/install.ps1 | iex
```

**Mac**：「ターミナル」アプリを開いて貼り付ける

```bash
curl -fsSL https://raw.githubusercontent.com/Waseda-Game-Co-creation-Studio/claude-proto-kit/main/install.sh | bash
```

### 2. Claude を起動する

新しく PowerShell（Mac はターミナル）を開き、`claude` と入力して Enter。初回はブラウザでログインします。
Claude の有料プラン（Pro 以上）か、Anthropic Console のアカウントが必要です。

Claude のデスクトップアプリを使う場合は、「Code」タブでフォルダを選ぶだけで同じように使えます。

### 3. 作りたいものを頼む

ふつうの言葉で話しかけます。たとえば：

- 「矢印キーで動いて、落ちてくる岩をよけるミニゲームを作って」
- 「玉を転がしてゴールを目指す 3D のゲームを作って。スマホでも遊べるように」
- 「もっと難しくして」「ジャンプを高くして」（作ったあとの調整も言葉で）
- 「このゲームの企画を説明するスライドを作って」
- 「遊んでいる様子がわかる 15 秒の紹介動画を作って」
- 「公開して、URL を教えて」

フォルダの準備や、必要なログインの案内は Claude が自動でやります。

### 何を作るかの伝え方

Claude は、あなたの言葉と、渡した資料をもとに作ります。

- **やりたいことを具体的に**：「どんなゲームか」「どう操作するか」「何をしたらクリア／ゲームオーバーか」
- **資料があれば渡す**：企画書やメモのファイルを、Claude の画面にドラッグするか「`企画.md` をもとに」と書く
- **足りないときは Claude が質問します**。「おまかせで」と言えば、Claude が決めて作ります

## 公開について

初めて公開するときは、Cloudflare（無料で使えます）のアカウントが必要です。手順は Claude が案内します。
公開した URL は、知っている人なら誰でも見られます。パスワードや個人情報は入れないでください。

## 近道コマンド（使わなくても大丈夫）

言葉で頼む代わりに、`/` で始まるコマンドでも同じことができます。

| コマンド | すること |
| --- | --- |
| `/new web 名前 内容` | ゲームなどの試作品を作る（例：`/new web dodge 岩をよけるミニゲーム`） |
| `/new slides 名前 内容` | スライドを作る（例：`/new slides pitch dodge の企画説明`） |
| `/new pv 名前 内容` | 動画を作る |
| `/deploy` | 公開して URL を返す |
| `/render` | 動画を書き出して、見られる URL を返す |
| `/capture URL` | Web ページを自動で操作する様子を録画し、デモ動画にする |
| `/proto-init` | フォルダの準備だけを先にする（ふだんは自動） |
